SPINFORGE · 4/4

Stack technique

Web d'abord (PWA), mobile ensuite (Capacitor). TypeScript + Vite, cœur de simulation pur, PixiJS pour l'arène, React pour les menus.

L'architecture qui rend l'idle possible

La règle d'or : le rendu n'est jamais source de vérité. Le cœur du jeu est une simulation à tick fixe, sans aucune dépendance au DOM ni à PixiJS. Les gains hors-ligne, c'est juste min(temps écoulé, plafond) ÷ tick ticks rejoués en accéléré à la reconnexion — au-delà d'une heure, une formule fermée fait le même calcul instantanément. Anti-triche minimal : clamp du delta temps, horodatage serveur le jour où un backend existera.

Pourquoi ces choix

BRIQUEJUSTIFICATION
TypeScript + ViteItération instantanée ; les types protègent l'économie (une monnaie n'est pas un nombre nu).
PixiJS2D léger, 60 fps — toupies, pièges d'arène, particules ; bien plus simple que Phaser pour « une seule scène ».
React90 % du jeu est de l'UI : forge, inventaire, coffres, arbre de Refonte. C'est son terrain.
break_infinity.jsProgression infinie = nombres au-delà de 2⁵³. La lib de référence des incrémentaux.
PWA → CapacitorDistribution web instantanée pour itérer, empaquetage stores quand le jeu tient.
Pas d'Unity / GodotOverkill pour un idle 2D piloté par l'UI ; le web itère et se partage plus vite.

Les données comme contenu

Tout le catalogue — toupies, pièces, arènes, courbes, coffres — vit dans des fichiers JSON statiques versionnés, jamais dans le code. Équilibrer le jeu ou lancer une saison = éditer des données. C'est aussi ce qui permettra un jour un équilibrage à chaud côté serveur.

Jalons — jouable à chaque étape

JALON 1 — LA BOUCLE NUE

Pilotage au doigt (glisser-diriger), simulation de combat, salles et boss, crédits, améliorations de pièces, 1 arène. Déjà jouable : on pilote, ça monte.

JALON 2 — LE GACHA

Coffres, inventaire, fusion 3→1, échelle de rareté complète, 4 toupies Fondateurs.

JALON 3 — L'IDLE

Farm hors-ligne plafonné, mode AUTO sur chapitres validés, murs calibrés, chapitres 1-4, quêtes quotidiennes.

JALON 4 — LE LONG TERME

Refonte + arbre d'atouts, Génération Rafale, chapitres 5-8 — dont le Vortex, le chapitre infini —, premier événement.
